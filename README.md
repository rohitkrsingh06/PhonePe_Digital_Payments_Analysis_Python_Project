# 📊 PhonePe Digital Payments Data Analysis

## 📌 Project Overview
This project analyzes PhonePe digital payments data across states and districts to understand transaction trends, user behavior, device usage, and regional differences.

The dataset includes multiple sheets covering state-level and district-level transactions, user data, device information, and demographics.

---

## 📁 Dataset Information

*File Name:*
phonepe_digital_payments.xlsx

### 📑 Sheets Included:
1. State_Txn and Users  
2. State_TxnSplit  
3. State_DeviceData  
4. District_Txn and Users  
5. District Demographics  
6. Admin  

---

## 📊 Key Insights

### 🔹 1. Transaction Growth Trends
- Transactions and app opens show a consistent upward trend over time.
- Growth is not uniform; some quarters show spikes (seasonal or campaign-driven).

*Insight:* User adoption is increasing, but engagement is uneven.

---

### 🔹 2. State-Level Variations
- Some states dominate in total transaction volume and value.
- Other states show lower volume but higher average transaction value (AvgTV).

*Insight:* High volume does not always mean high value.

---

### 🔹 3. Average Transaction Value (AvgTV)
- States with fewer users sometimes show higher AvgTV.
- Indicates premium or high-income user segments.

*Insight:* Clear distinction between mass-market and premium users.

---

### 🔹 4. Transaction Type Distribution
- A few transaction types dominate (P2P, recharge, merchant payments).
- Distribution is highly imbalanced.

*Insight:* User behavior is concentrated.

---

### 🔹 5. Device Brand Usage
- A few smartphone brands dominate usage (Xiaomi, Samsung, Vivo).
- Device preference varies by state.

*Insight:* Regional device ecosystem influences usage patterns.

---

### 🔹 6. Population vs Transactions
- Weak to moderate correlation observed.
- High population does not guarantee high transaction volume.

*Insight:* Digital adoption matters more than population size.

---

### 🔹 7. Data Discrepancies
- Differences observed between state and district-level aggregation.

*Insight:* Possible data quality or aggregation mismatch issues.

---

## 📌 Recommendations

### 🔹 Focus on High-Value States
- Target states with high AvgTV
- Promote premium financial services

### 🔹 Improve Low-Engagement Regions
- Awareness campaigns
- Cashback and onboarding improvements

### 🔹 Diversify Transaction Types
- Promote merchant payments
- Reduce dependency on P2P transactions

### 🔹 Device-Based Optimization
- Optimize app performance for dominant device brands
- Run device-specific campaigns

### 🔹 Data-Driven Strategy
- Focus on internet penetration and digital literacy over population alone

### 🔹 Seasonal Strategy
- Identify peak quarters
- Launch campaigns before high activity periods
